Gobuster

Directory, file, and vhost brute-forcing with Gobuster — flag reference plus ready-to-run command patterns for the common scenarios.

Flag Reference (dir mode)

Flag Meaning
-u Target URL
-w Wordlist path
-x File extensions to append to each word (e.g. php,txt,bak,zip,old)
-s Status codes to treat as positive (whitelist) — e.g. 200,204,301,302,307,401,403
-b Status codes to ignore (blacklist) — e.g. 404
-t Threads (default 10; 40–80 is a reasonable fast range)
-k Skip TLS certificate verification (needed for self-signed / lab HTTPS)
-a Custom User-Agent string (e.g. "Mozilla/5.0")
-o Write results to an output file
--wildcard Continue even when the server returns wildcard (catch-all) responses
--delay Delay between requests (e.g. 500ms) — throttle for rate-limited / IDS-watched targets

Note: newer Gobuster versions favour -b (blacklist) over -s (whitelist); pick one, not both. If every path returns the same code, the server has a catch-all — add --wildcard or filter by response size with ffuf/feroxbuster instead.

Core Directory Scans

# Basic scan
gobuster dir -u https://target.com -w common.txt

# With file extensions
gobuster dir -u https://target.com -w medium.txt -x php,txt,bak,zip,old

# Whitelist interesting status codes
gobuster dir -u https://target.com -w medium.txt -s 200,204,301,302,307,401,403

# Blacklist 404s (modern default style)
gobuster dir -u https://target.com -w medium.txt -b 404

# More threads (faster)
gobuster dir -u https://target.com -w medium.txt -t 80

# Skip TLS verification (self-signed / lab certs)
gobuster dir -u https://target.com -w medium.txt -k

# Custom User-Agent (blend in / bypass simple UA filters)
gobuster dir -u https://target.com -w medium.txt -a "Mozilla/5.0"

# Save output
gobuster dir -u https://target.com -w medium.txt -o gobuster_dir.txt

# Handle wildcard / catch-all responses
gobuster dir -u https://target.com -w medium.txt --wildcard

# Throttle requests (rate-limited or monitored targets)
gobuster dir -u https://target.com -w medium.txt --delay 500ms

Targeted Path Scans

# Admin area with web extensions
gobuster dir -u https://target.com/admin -w admin.txt -x php,html,js

# API path with data extensions
gobuster dir -u https://target.com/api -w api.txt -x json,xml

Standard Wordlist Rotation

Run the same host through progressively larger lists. -k keeps it working against self-signed HTTPS.

gobuster dir -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,txt,bak,zip -k
gobuster dir -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt -x php,txt,bak,zip -k
gobuster dir -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -x php,txt,bak,zip -k
gobuster dir -u https://target.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,bak,zip -k

Sweeping Discovered Subdomains

Once subdomain enumeration turns up hosts (api, dev, staging, admin), content-scan each one — different vhosts almost always expose different apps.

Quick pass (each host, small list):

gobuster dir -u https://api.target.com -w common.txt
gobuster dir -u https://dev.target.com -w common.txt
gobuster dir -u https://staging.target.com -w common.txt
gobuster dir -u https://admin.target.com -w common.txt

Full wordlist rotation per host — substitute the hostname and run the same four lists:

# Pattern (repeat per host: api / dev / staging / admin)
gobuster dir -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,txt,bak,zip -k
gobuster dir -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt -x php,txt,bak,zip -k
gobuster dir -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -x php,txt,bak,zip -k
gobuster dir -u https://<HOST>.target.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,bak,zip -k

Loop it instead of pasting 16 commands:

for host in api dev staging admin; do
  for wl in \
    /usr/share/seclists/Discovery/Web-Content/common.txt \
    /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt \
    /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
    /usr/share/wordlists/dirb/common.txt; do
    echo "=== $host : $(basename $wl) ==="
    gobuster dir -u "https://$host.target.com" -w "$wl" -x php,txt,bak,zip -k \
      -o "gobuster_${host}_$(basename $wl .txt).txt"
  done
done

Other Modes

# DNS subdomain brute-force
gobuster dns -d target.com -w /usr/share/seclists/Discovery/DNS/subdomains-top1million-5000.txt -r <DNS_IP>

# Virtual host fuzzing (--append-domain adds the base domain to each word)
gobuster vhost -u https://target.com -w <wordlist> --append-domain -k
