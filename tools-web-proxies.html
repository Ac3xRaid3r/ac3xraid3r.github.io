BurpSuite Setup

Proxy Configuration

Browser → Proxy (127.0.0.1:8080) → Target

Install Burp CA certificate:

  1. Navigate to http://burp
  2. Download certificate
  3. Import to browser (or system certificate store)

Burp Shortcuts

Shortcut Action
CTRL+U URL-encode selected text
CTRL+SHIFT+U URL-decode selected text
CTRL+R Send to Repeater
CTRL+I Send to Intruder
CTRL+SHIFT+R Force refresh (in browser)

Match & Replace

Auto-modify requests and responses based on rules.

Location: Proxy > Proxy Settings > HTTP match and replace rules

Replace User-Agent

Type:    Request header
Match:   ^User-Agent.*$
Replace: User-Agent: HackTheBox Agent 1.0
Regex:   ☑

Enable Text Input (Bypass Validation)

Type:    Response body
Match:   type="number"
Replace: type="text"

Increase maxlength Attribute

Type:    Response body
Match:   maxlength="3"
Replace: maxlength="100"

Common Match & Replace Patterns

Use Case Match Replace
Custom User-Agent ^User-Agent.*$ User-Agent: CustomAgent
Add Header (empty) X-Custom-Header: value
Change Referer ^Referer.*$ Referer: https://trusted.com
Enable text input type="number" type="text"
Remove maxlength maxlength="3" maxlength="1000"
Enable button disabled (empty)
Show hidden field type="hidden" type="text"
Remove readonly readonly (empty)

Decoder

Decode, encode, or hash data within Burp.

Location: Decoder tab

Actions:

  • Decode as (URL, HTML, Base64, ASCII Hex, Unicode)
  • Encode as (various formats)
  • Hash (MD5, SHA-1, SHA-256, etc.)
  • Smart decode (auto-detect format)

Supported Formats:

  • URL encoding
  • HTML entities
  • Base64
  • ASCII Hex
  • Unicode

Inspector

Auto-decode and chain decoding within request/response context.

Location: Proxy/Repeater → right side panel

Features:

  • Auto-decode selected text
  • Chain multiple decodings
  • Apply changes in-context

java -jar zaproxy.jar
## Proxy: 127.0.0.1:8080

Key Shortcuts

Shortcut Action
CTRL+E Encoder/Decoder/Hash

ZAP Replacer

Auto-modification rules in ZAP.

Location: CTRL+R or Tools > Options > Replacer

Example Rule

Description:      HTB User-Agent
Match Type:       Request Header (will add if not present)
Match String:     User-Agent
Replacement:      HackTheBox Agent 1.0
Enable:           ☑

Common Rules

Description Match Type Match String Replacement
Custom UA Request Header User-Agent CustomAgent 1.0
Add Auth Request Header (empty) Authorization: Bearer token
Change Referer Request Header Referer Referer: https://trusted.com
Enable field Response Body type="number" type="text"
Remove readonly Response Body readonly (empty)

Encoding/Decoding Reference

URL Encoding Key Characters

Character Encoded Purpose
Space %20 or + End of request data
& %26 Parameter delimiter
# %23 Fragment identifier
= %3D Parameter assignment
? %3F Query string start
/ %2F Path separator
+ %2B Space in form data
: %3A Scheme/host separator
; %3B Parameter separator
! %21 Unreserved

Common Encodings

Encoding Example Use

Hex 48656c6c6f Binary representation
Unicode He JavaScript strings

Cookie Manipulation Workflow

1. Identify Encoded Cookie

Cookie: session=eyJ1c2VybmFtZSI6Imd1ZXN0IiwgImlzX2FkbWluIjpmYWxzZX0=

2. Decode (Base64)

{"username":"guest", "is_admin":false}

3. Modify Values

{"username":"admin", "is_admin":true}

4. Re-encode (Base64)

eyJ1c2VybmFtZSI6ImFkbWluIiwgImlzX2FkbWluIjp0cnVlfQ==

5. Replace Cookie and Test

Cookie: session=eyJ1c2VybmFtZSI6ImFkbWluIiwgImlzX2FkbWluIjp0cnVlfQ==

40 chars   → SHA-1

128 chars  → SHA-512
$2a$      → Bcrypt
$6$       → SHA-512 crypt
