Recursive content discovery with Feroxbuster — a flag reference plus ready-to-run patterns. Feroxbuster's edge over Gobuster dir is automatic recursion: it forks a new scan into every directory it finds, so one command walks the whole tree.

Flag Reference

Flag Meaning
-u Target URL
-w Wordlist path (defaults to a built-in list if omitted)
-x File extensions to append to each word (e.g. php,txt,bak,zip,old)
--depth Maximum recursion depth (default 4; --depth 0 = unlimited)
--scan-limit Cap concurrent directory scans — throttles the recursion fan-out
--threads / -t Threads per scan (default 50; 80 is a reasonable fast range)
-k Skip TLS certificate verification (self-signed / lab HTTPS)
-H Add a request header — repeatable (cookies, bearer tokens, custom UA)
-n No recursion — single-level scan, behaves like gobuster dir
-o Write results to an output file
--filter-size Drop responses of a given byte size (kill catch-all noise)
--filter-status / -C Drop responses by status code (e.g. 404)

Note: Feroxbuster recurses by default, which is powerful but loud. On a large or rate-limited target, rein it in with --scan-limit and --depth, or shut recursion off entirely with -n. When every path returns the same size, filter it out with --filter-size <bytes> rather than chasing false positives.

Core Scans

# Simplest scan — built-in wordlist, recursion on
feroxbuster -u https://target.com

# Specify a wordlist
feroxbuster -u https://target.com -w medium.txt

# Append file extensions
feroxbuster -u https://target.com -x php,txt,bak,zip,old

# Control recursion depth
feroxbuster -u https://target.com --depth 5

# Cap concurrent directory scans (tame the fan-out)
feroxbuster -u https://target.com --scan-limit 10

# More threads (faster)
feroxbuster -u https://target.com --threads 80

# Skip TLS verification (self-signed / lab certs)
feroxbuster -u https://target.com -k

# No recursion — single level, like gobuster dir
feroxbuster -u https://target.com -n

# Save output
feroxbuster -u https://target.com -o ferox_output.txt

Authenticated Scans

Carry a session so you discover everything behind the login, not just the public tree.

# Session cookie
feroxbuster -u https://target.com -H "Cookie: session=TOKEN"

# Bearer token (APIs / SPAs)
feroxbuster -u https://target.com -H "Authorization: Bearer TOKEN"

Filtering Out Noise

# Drop empty bodies and 404s — classic catch-all cleanup
feroxbuster -u https://target.com --filter-size 0 --filter-status 404

Standard Wordlist Rotation

Run the host through progressively larger lists, each capped at --depth 3 so recursion stays bounded. -x appends the usual file extensions.

feroxbuster -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://target.com -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://target.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,bak,zip --depth 3

Sweeping Discovered Subdomains

Once subdomain enumeration turns up hosts (api, dev, staging, admin), content-scan each one — different vhosts almost always expose different apps.

Pattern — substitute the hostname and run the same four lists:

# Repeat per host: api / dev / staging / admin
feroxbuster -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/common.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://<HOST>.target.com -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt -x php,txt,bak,zip --depth 3
feroxbuster -u https://<HOST>.target.com -w /usr/share/wordlists/dirb/common.txt -x php,txt,bak,zip --depth 3

Loop it instead of pasting 20 commands:

for host in api dev staging admin; do
  for wl in \
    /usr/share/seclists/Discovery/Web-Content/common.txt \
    /usr/share/seclists/Discovery/Web-Content/raft-small-words.txt \
    /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-small.txt \
    /usr/share/wordlists/dirb/common.txt; do
    echo "=== $host : $(basename $wl) ==="
    feroxbuster -u "https://$host.target.com" -w "$wl" -x php,txt,bak,zip --depth 3 \
      -o "ferox_${host}_$(basename $wl .txt).txt"
  done
done

Gobuster vs Feroxbuster

Gobuster dir Feroxbuster
Recursion Manual (re-run per path) Automatic — forks into every found dir
Default behaviour One level Recurses to --depth 4
Throttling recursion n/a --scan-limit, --depth
Best for Fast, flat, predictable scans Walking an unknown tree in one shot

Reach for Feroxbuster when you want the whole directory tree mapped automatically; reach for Gobuster when you want a quick, controlled single-level sweep.
